# Lulu's Road Trip 🚗💨

A cute Sneaky-Sasquatch-style driving game where Lulu tries not to crash. Built with plain HTML + JavaScript — no server, no install, no tracking. Plays locally in your browser.

**🎮 Play it at: [lulu.boats](https://lulu.boats)**

## Features
- 🚗 8 unlockable car skins
- 🚀 Missile power-ups
- 🦒 Animals, pedestrians (pick them up as passengers!)
- 💥 Crash sequence with an angry white-haired man yelling at you
- 📱 Distracted-mode (reversed controls, 2× score)
- 📲 Mobile-friendly with touch controls
- 💾 Saves your coins and unlocks locally — no account needed

## Controls

**Desktop:** ← → steer · ↑ boost · ↓ slow · M missile · P pause

**Mobile:** Touch to steer · on-screen buttons for boost/brake/missile/pause
